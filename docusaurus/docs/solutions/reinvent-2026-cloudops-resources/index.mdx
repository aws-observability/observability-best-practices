Your one-stop location for Cloud Operations resources: blogs, best-practices guides, interactive demos, workshops, and documentation for observability, CloudWatch Omni, and operations on AWS.

## When to use this

- You are new to a Cloud Operations topic and want a curated place to start before going deeper.
- You want hands-on experience with a service or capability, such as [Amazon CloudWatch Omni](https://aws.amazon.com/cloudwatch/omni/), through interactive demos and workshops.
- You are enabling a team or customers on cloud operations (observability, AWS CloudTrail, AWS DevOps Agent, OpenTelemetry, or MCP tools for AI assistants) and want one shareable link to current material.
- You want to find Cloud Operations resources by format (video, blog, guide, demo, workshop) or by topic without searching across multiple AWS sites.
