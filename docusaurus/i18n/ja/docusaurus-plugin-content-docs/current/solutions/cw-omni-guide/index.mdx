# Amazon CloudWatch Omni の紹介

## 概要

[Amazon CloudWatch Omni](https://aws.amazon.com/cloudwatch/omni/) は [Amazon CloudWatch](https://aws.amazon.com/cloudwatch/) の次世代版です：AI を活用し、オープンスタンダード上に構築され、AWS コンソール外で提供される、再構想されたオブザーバビリティエクスペリエンスです。AI 時代のために設計された CloudWatch Omni は、AI エージェント、アプリケーション、インフラストラクチャのモニタリングを単一のソリューションに統合します。

Omni はオペレーター向けのスタンドアロン Web UI と開発者向けのネイティブ IDE 拡張機能の両方として提供されるため、コードをローカルで実行した瞬間にエージェントトレースが表示されます。[OpenTelemetry](https://opentelemetry.io/) 上に構築されています：既に CloudWatch に送信しているテレメトリは再設定なしで Omni に表示され、OpenTelemetry で計装した他のワークロードは OpenTelemetry Protocol（OTLP）エンドポイントにテレメトリを送信します。

Omni は CloudWatch 統合データストア上に位置するため、エージェントの動作をアプリケーションの健全性からインフラストラクチャまで接続します — エージェントの推論、古いナレッジベース、下流のレイテンシスパイクなど、真の根本原因を見つけることができます。

### 役割に合ったインターフェースを選択する

CloudWatch Omni はオペレーターと開発者が作業する場所で対応します。

<Tabs>
  <TabItem value="operators" label="オペレーター（Web UI）" default>

オペレーター向けに構築された**オフコンソール Web エクスペリエンス**を通じて Omni にアクセスします：Omni スペース、アプリケーションマップ、サービス、ダッシュボード、アラート、評価ダッシュボード、およびガイド付き調査 — すべて AWS コンソール外で。

  </TabItem>
  <TabItem value="developers" label="開発者（IDE）">

**VS Code、Kiro、Cursor 向けのネイティブ IDE 拡張機能**を使用します。コードをローカルで実行した瞬間にエージェントトレースが表示されるため、開発者はエディターを離れることなくエージェントの動作を観察・評価できます。

  </TabItem>
</Tabs>

**なぜ重要か：** エージェントをローカルでデバッグする人と本番環境のインシデントをトリアージする人は、同じデータに対して異なるサーフェスが必要です。単一のインターフェースでのトレードオフ：2 つのオーディエンスのいずれか一方が常に不利な条件で作業することになります。
