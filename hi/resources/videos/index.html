प्रमुख वीडियो

लॉग डेटा ट्रांसफ़ॉर्मेशन​

  • Amazon CloudWatch Log Transformation जानें कि अपने लॉग डेटा को आसानी से कैसे ट्रांसफ़ॉर्म और एनालिसिस करें।

ऑपरेशनल जाँच​

  • Operational Investigations with Amazon Q Developer Amazon Q Developer का उपयोग करके ऑपरेशनल समस्याओं की जाँच कैसे करें यह जानें।

ECS के साथ उन्नत ऑब्ज़र्वेबिलिटी​

  • Enhanced ऑब्ज़र्वेबिलिटी on ECS with Amazon CloudWatch Container Insights देखें कि अपने ECS कंटेनराइज़्ड एप्लिकेशन में गहरी अंतर्दृष्टि कैसे प्राप्त करें।

नेटवर्क फ़्लो मॉनिटरिंग​

  • Flow Monitoring with Amazon Network Flow Monitor नेटवर्क फ़्लो की निगरानी करना और संभावित सुरक्षा खतरों की पहचान करना सीखें।

CloudWatch Database Insights​

  • Amazon CloudWatch Database Insights हमारी नवीनतम database insights सुविधा के साथ हैंड्स-ऑन अनुभव प्राप्त करें।

इंटरैक्टिव OpenSearch डैशबोर्ड​

  • Native OpenSearch Dashboards in AWS CloudWatch अपने लॉग डेटा के लिए इंटरैक्टिव, विज़ुअल डैशबोर्ड कैसे बनाएँ यह जानें।

PPL और SQL के साथ उन्नत क्वेरी​

  • OpenSearch SQL & PPL Query Languages Support in AWS CloudWatch Logs OpenSearch SQL & PPL का उपयोग करके शक्तिशाली क्वेरी लिखना सीखें।

फ़ील्ड इंडेक्स और ट्रांज़ैक्शन सर्च​

  • Amazon CloudWatch Field Indexes

  • Amazon CloudWatch Transaction Search रीयल-टाइम में ट्रांज़ैक्शनल समस्याओं की पहचान और जाँच कैसे करें देखें।

Application Signals और सर्वरलेस टेलीमेट्री​

  • Application Signals with AWS Lambda अपने सर्वरलेस एप्लिकेशन में गहरी अंतर्दृष्टि कैसे प्राप्त करें सीखें।

CloudWatch Explore सुविधा​

  • Exploring Amazon CloudWatch's explore feature हमारी नवीनतम टेलीमेट्री सुविधा से अपने AWS संसाधनों का अधिकतम लाभ कैसे उठाएँ जानें।

ट्रांज़ैक्शन सर्च और एनालिटिक्स​

  • Amazon CloudWatch Transaction Search and Analytics हमारी नवीनतम ट्रांज़ैक्शन सर्च सुविधा के साथ हैंड्स-ऑन अनुभव प्राप्त करें।
