AWS CloudTrail வளங்கள்

உங்கள் AWS CloudTrail பாதுகாப்பு நடைமுறைகளை வலுப்படுத்தவும், incident response-ஐ மேம்படுத்தவும், monitoring திறன்களை மேம்படுத்தவும் தொகுக்கப்பட்ட வளங்களை ஆராயுங்கள். இந்த பக்கம் இரண்டு பிரிவுகளாக பிரிக்கப்பட்டுள்ளது: practical guidance-க்கான AWS Blog Posts மற்றும் பொதுவான பாதுகாப்பு scenarios-ன் hands-on simulations-க்கான AWS CloudTrail Workshops.

AWS Blog Posts​

இந்த blog posts உங்கள் AWS environment-ஐ பாதுகாக்கவும், incidents-ஐ கண்டறியவும், responses-ஐ automate செய்யவும் AWS CloudTrail-ஐ பயன்படுத்துவதற்கான actionable insights-ஐ வழங்குகின்றன. வளங்கள் எளிதான navigation-க்காக focus area-வாக grouped செய்யப்பட்டுள்ளன.

Incident Investigation மற்றும் Forensics​

  • CloudTrail Lake-உடன் Security Events-ஐ விசாரித்தல்
    Compromised access keys போன்ற security incidents-ஐ பகுப்பாய்வு செய்ய CloudTrail Lake queries-ஐ பயன்படுத்துங்கள்.
  • CloudTrail Insights: அசாதாரண API Activity-ஐ கண்டறிதல்
    CloudTrail Insights-உடன் anomalous API calls-ஐ கண்டறிந்து respond செய்ய கற்றுக்கொள்ளுங்கள்.
  • CloudTrail Lake அறிவிப்பு - Managed Audit and Security Lake
    மையப்படுத்தப்பட்ட audit மற்றும் security log management-க்கான CloudTrail Lake-ஐ கண்டறியுங்கள்.

Monitoring மற்றும் Alerts​

  • Root User Activity-ஐ கண்காணித்தல்
    மேம்படுத்தப்பட்ட பாதுகாப்புக்காக AWS account root user activity-ஐ track செய்ய notifications அமைக்கவும்.
  • IAM Access Key Usage-க்கான Alerts
    IAM access keys பயன்படுத்தப்படும்போது கண்டறிய alerts configure செய்யுங்கள்.
  • IAM Configuration Changes-க்கான Notifications
    IAM configurations-ல் மாற்றங்களுக்கான alerts-ஐ implement செய்யுங்கள்.
  • IAM User Creation-ஐ கண்காணித்தல்
    அங்கீகரிக்கப்படாத மாற்றங்களை கண்டறிய புதிய IAM user creation-க்கான notifications அமைக்கவும்.
  • Account மற்றும் EC2 Security Group Changes-ஐ Track செய்தல்
    EC2 security groups-க்கான configuration changes மற்றும் API calls-ஐ monitor செய்யுங்கள்.
  • CloudWatch-ல் CloudTrail-ஐ பகுப்பாய்வு செய்தல்
    Real-time log analysis-க்கு CloudTrail-ஐ CloudWatch-உடன் integrate செய்யுங்கள்.

Security Best Practices மற்றும் Automation​

  • CloudTrail Modifications-ஐ தடுத்தல்
    அங்கீகரிக்கப்படாத மாற்றங்களிலிருந்து CloudTrail-ஐ பாதுகாக்க நுட்பங்களை கற்றுக்கொள்ளுங்கள்.
  • Compromised Access Keys-க்கான Responses-ஐ Automate செய்தல்
    வெளிப்பட்ட access keys-க்கான responses-ஐ automate செய்ய GitHub tools-ஐ பயன்படுத்துங்கள்.

AWS CloudTrail Workshops​

இந்த hands-on workshops பொதுவான security events-ஐ simulate செய்து AWS CloudTrail மற்றும் தொடர்புடைய services பயன்படுத்தி detection மற்றும் response-ஐ demonstrate செய்கின்றன. ஒவ்வொரு workshop-லும் real-world scenarios-ஐ replicate செய்ய CloudFormation template அல்லது script உள்ளது.

Workshop பட்டியல்​

  • அங்கீகரிக்கப்படாத IAM Credential பயன்பாடு
    விளக்கம்: CloudShell script வழியாக அங்கீகரிக்கப்படாத IAM credential பயன்பாட்டை simulate செய்தல், reconnaissance மற்றும் privilege escalation-ஐ mimicking செய்தல்.
    ஏன் முக்கியம்: AWS environments-ல் பொதுவான attack vector ஆன அங்கீகரிக்கப்படாத அணுகலை detect செய்யவும் mitigate செய்யவும் கற்றுக்கொள்ளுங்கள்.

  • S3-ல் Ransomware
    விளக்கம்: S3 buckets உருவாக்கி CloudShell-ல் data exfiltration மற்றும் deletion வழியாக ransomware-ஐ simulate செய்ய CloudFormation template பயன்படுத்துதல்.
    ஏன் முக்கியம்: அங்கீகரிக்கப்படாத S3 modifications-ஐ detect செய்வதன் மூலம் data loss அல்லது exposure-லிருந்து பாதுகாத்தல்.

  • Cryptominer Security Events
    விளக்கம்: அறியப்பட்ட domains-க்கு DNS requests மூலம் cryptomining-ஐ simulate செய்ய CloudFormation வழியாக EC2 instances deploy செய்தல்.
    ஏன் முக்கியம்: செலவுகளை குறைக்கவும் EC2 instances-ஐ பாதுகாக்கவும் resource-intensive cryptomining-ஐ கண்டறிதல்.

  • IMDSv1-ல் SSRF
    விளக்கம்: IMDSv1 vulnerabilities வழியாக EC2 instance credentials-ல் server-side request forgery (SSRF) attack-ஐ simulate செய்தல்.
    ஏன் முக்கியம்: SSRF mitigation மூலம் instance credentials-க்கான அங்கீகரிக்கப்படாத அணுகலை தடுத்தல்.

CloudTrail-உடன் தொடங்குங்கள்

விரிவான வழிகாட்டுதலுக்கு, security monitoring, incident response மற்றும் best practices-ஐ master செய்ய AWS CloudTrail User Guide-ஐ ஆராயுங்கள்.
